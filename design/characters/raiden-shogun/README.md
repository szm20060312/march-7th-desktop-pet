## 来源与生成

全部姿态由内置 ImageGen 实际生成；使用仓库原三月七图作为比例/线条参考，再以用户确认的雷电将军基准图约束后续动作。没有使用CLI/API替代生成或把单张静态图复制成动画。生成要求和所用参考见 `PROMPTS.md`。

只保留本次选用源图。初次右跑触边、初次注视图无法安全分帧、初次左跑缺肩甲等候选被拒绝，未进入此图集。左跑肩甲是整行重生成修复，不是对最终单帧手工补画。

本资源是非官方同人角色表现，不代表原角色权利方或平台的授权/背书，也不声明拥有角色设计权。公开分发与商业化仍遵守项目长期计划中的素材范围核对及独立决策条件。

## 可复现组装

参考环境：Python3、Pillow12.3.0、numpy2.3.5。

```sh
python assemble_preview.py
```

脚本只对真实生成图进行分帧、统一行缩放和图集组装，不生成新姿态。默认结果在被Git忽略的 `qa-generated/`。可将其图集哈希与 `qa/manifest.json` 对照；不要未经检查就覆盖应用候选文件。

优先按独立水平区域提取；左跑图中的人物在二维alpha上相互分离，但横向范围重叠，因此使用alpha连通区域隔离。184个微小分离alpha像素被排除并记录；独立审查未看到主体缺损，但没有逐一确认这些像素的性质，不能宣称逐像素无损。

每行只使用一个垂直范围和缩放，保留跳跃的相对高度，不能逐帧对齐脚底抹掉动作。
