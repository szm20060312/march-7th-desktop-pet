# M0—M5 桌面回归测试包（按 sourceCommit 区分能力）

这个包用于验证当前提交的真实桌面行为。应用版本号仍为 v0.2.0；本地技术候选已经接入托盘与穿透、位置保存、双角色互动、默认全关的日常提醒、本地备份、单会话专注和一个可选当前任务。**这些能力是否存在以包内完整 sourceCommit 为准**，构建成功不代表 Windows/Mac 实机、朋友试用或 M5 产品验收通过。

历史 M0 包按该 sourceCommit 随包文档测试；本清单新增能力仅适用于包含相应实现的当前构建，不追溯改变旧包能力或验收结果。

包含 G7-B1 的构建在同一配置目录只允许一个采用新协议的可写实例，第二次启动正常结束，不唤醒已有窗口。升级前仍须先退出旧版。`instance.lock` 会保留，文件存在不表示程序仍运行，不要删除它来解锁。目录或锁不可用时角色临时选择、提醒关闭且只读、位置不可保存，专注状态也不可持久写入；不会换目录或覆盖原配置。对应验证见共用清单 G7-B1/M5 段，自动子进程锁测试不替代双平台 GUI。

## 先确认版本

1. 优先从项目 GitHub Actions 的 **Desktop Regression Builds** 同一次成功运行下载两平台 artifact；也可先使用开发者提供并注明完整提交的本地 Windows 测试包做单平台预查。Mac 与 Windows 的里程碑验收仍须同一个 `sourceCommit`。GitHub 下载可能要求登录。
2. 解压到一个新的测试目录，不覆盖旧版或旧 Codex 宠物包。
3. 打开 `BUILD-INFO.json`，记录完整 `sourceCommit`、`target` 和 `buildRunUrl`。本地构建的 `buildRunUrl` 可为 null，应另记录提供者与本地构建证据；不能冒称已有 Mac 同提交 CI。Windows 与 Mac 必须测试同一 `sourceCommit`；只比较 `0.2.0` 版本号不够。
   对包含 G7-A 的构建，再从托盘打开提醒设置，展开“版本信息”，核对完整提交、版本和平台；应显示“构建输入无本地修改”。该版本的 manifest 还含 `binaryBuildInfo`，由 CI 对本次实际程序读取核对；它不证明素材授权、签名或 GUI 验收。
4. 包内 `validationStatus` 固定为 `build-only-awaiting-human-regression`，不可把它改成测试结果。
5. 按 [CHECKLIST.md](CHECKLIST.md) 测试，将结果填写到 [RESULT-TEMPLATE.md](RESULT-TEMPLATE.md) 的副本。

包包含一个平台程序、三份测试文档、`BUILD-INFO.json` 和 `SHA256SUMS.txt`。SHA-256 用于校验下载内容；从项目对应运行获取文件并核对来源。

## Windows 10/11 x64

- 程序是 `march-7th-app.exe`，不是安装器；无需安装 Node.js、pnpm、Rust 或编译工具。
- 运行前关闭旧的 March 7th 实例，再双击本包 exe。需要 Microsoft Edge WebView2 Runtime；若缺失导致启动失败，记录原始提示及系统版本，按微软官方说明安装运行时后重新测试。
- 正常停止请从系统托盘的 March 7th 菜单选择“退出”，等待进程结束；这会走异步末次位置保存。托盘图标可能在系统的隐藏图标区域。
- 仅在应用无响应时，才在任务管理器“详细信息”中找到**本次启动的** `march-7th-app.exe`，核对进程 ID 后结束该进程。强制结束可能丢失尚未保存的位置，应单独记录，不能作为正常退出或位置持久化验收通过。不要关闭名称不确定的进程。
- 停止程序后即可移走测试目录；这不等同于验证安装包的卸载流程。

校验全部文件（在解压目录，用 PowerShell 执行）：

```powershell
Get-Content -LiteralPath .\SHA256SUMS.txt | ForEach-Object {
    $parts = $_ -split '  ', 2
    $actual = (Get-FileHash -LiteralPath $parts[1] -Algorithm SHA256).Hash.ToLowerInvariant()
    if ($actual -ne $parts[0]) { throw "校验失败：$($parts[1])" }
    Write-Host "OK $($parts[1])"
}
```

## macOS Apple Silicon（macOS 13+）

- artifact 解压后还有一份 `March 7th.app.zip`。先校验，再用 Finder 解压该内层 ZIP，得到 `March 7th.app`。内层压缩用于保留应用包的可执行权限。
- 关闭旧实例，再打开本次应用；不支持 Intel Mac，不需要安装开发工具链。
- 这是开发测试构建，没有 Developer ID 签名与公证。如系统阻止启动，先核对来源和校验结果，使用系统提供的针对该应用的允许打开流程；无法允许则记录为“启动受阻”，不要关闭全局系统保护。
- 正常停止请从菜单栏 March 7th 托盘菜单选择“退出”，等待异步末次位置保存并结束进程。
- 仅在应用无响应时使用“活动监视器”强制退出本次 March 7th 进程。强制结束可能丢失尚未保存的位置，应单独记录，不能作为正常退出或位置持久化验收通过。

在测试包目录校验：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

## 测试与反馈

先完成约 10—15 分钟基本交互检查，再按清单记录不同缩放、显示器与常驻表现。没有第二显示器时写“无设备”，不能勾选通过；暂时没时间长测时保留待测。

反馈包括：提交标识、平台/系统、显示器与缩放、具体操作、预期和实际结果。必要时由测试者自愿提供只含桌宠问题区域的截图或录屏；不需要桌面私密内容。

遇到无法启动、明显异常占用或影响正常操作时，先停止测试，记录现象。不要为了“完成验收”把未测项改成通过。

GitHub Actions artifact 默认保留 30 天；过期后重新生成并核对代码基线与提交标识。本包是可直接运行的回归程序，**不是**安装器；安装、升级、卸载需用另附的未签名候选和 [分发清单](../distribution-candidate/CHECKLIST.md) 单独验证。本包也不宣称托盘或 M5 功能已经实机通过。

## G6 提醒使用方式与证据

首次无提醒配置时三项全部关闭。托盘“提醒 → 提醒设置…”确认开关、间隔与时段后保存；关闭设置不会退出应用，也不会保存草稿。分钟预设是可调整偏好，不是健康建议。提醒数据全部在本机，无账号或云端；不另发 OS 通知或声音。

“完成”只处理选中的软件事项；“全部稍后”进入全局安静期；“收起”及自动约 10 秒无回应只隐藏当前展示，待处理仍可从托盘“查看待处理”恢复，空集合也有页面。角色隐藏/穿透不暂停提醒，换角色不重置提醒。暂停/恢复从托盘或设置直接操作；检查实际勾选与保存/错误提示。正常退出请用托盘“退出”。

## M5 专注与当前一件事快速入口

从托盘“当前专注…”进入现有设置窗；可选时长开始、暂停、继续或结束一场会话。可选填一个当前任务名，任务完成/放弃与计时结束是不同操作。专注期间日常提醒继续进入待处理，不主动弹；自然完成只在允许时借同一个气泡提示一次，旧完成仍可从托盘找回，不补弹历史周期。详细行为与旧备份迁移、安静期、角色回应的实测步骤见 [共用清单 M5 段](CHECKLIST.md)；台词和“不打扰”效果须由所有者/试用者判断。
