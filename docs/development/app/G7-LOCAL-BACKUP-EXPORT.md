# G7-B3b2：导出本地备份

设置窗口的“本地数据 → 导出备份…”会在打开系统保存对话框前，从运行中的角色与提醒服务、主窗口当前几何位置生成 B3a v1 备份字节。它不从配置目录拷贝旧文件。配置根受保护、角色或提醒状态不可保存、桌面启动或缩放恢复中、当前位置不可捕获时，导出会拒绝，既不使用默认坐标，也不启动对话框。主窗口隐藏或处于穿透模式不改变这些资格。

路径只由用户在原生对话框里选择；WebView 没有通用文件访问权限。对话框是非阻塞调用，关闭设置窗口会使等待中的操作失效。一个导出操作从打开对话框到写入结束占用唯一票据：旧窗口回调不能写文件，重复点击不能并行写入。取消不会创建文件。

新文件通过 `create_new` 独占创建；即使系统对话框已经提示覆盖，应用仍拒绝已有路径。完整写入并 `sync_all` 成功后才报告成功。短写、同步失败或其他 I/O 错误显示失败；新建文件中若留下不完整内容，用户需检查并手动删除，应用不根据路径盲目清理。备份不自动上传、不含图集、日志或其他应用数据。

本切片不包括导入、自动重启或 B2 数据集指针更改。自动测试覆盖备份写入、已有路径、短写/同步失败、票据并发与取消、前端窗口会话、提醒草稿隔离、类型/架构与构建。浏览器测试只核对设置页正常及窄布局；Windows/macOS 原生文件对话框、所选文件回读仍需两平台同提交实测，不以本地自动检查代替。
