# 安装候选实机清单

每个平台各填一份。状态仅用“通过／失败／待测／无设备／不适用”，注明实际观察。使用隔离用户、虚拟机或可恢复快照；不以真实日用数据做破坏性实验。

1. **身份**：记录完整提交、CI 运行、系统版本/架构；校验候选文件 SHA-256；核对程序内版本信息、target 和完整提交。Windows 与 Mac 必须同提交。
2. **干净安装**：从没有该应用的隔离环境安装，记录首次系统提示、WebView2 状态、所需网络、应用目录与快捷方式。Windows 核对当前用户安装范围和是否要求管理员权限。Mac 核对 DMG 打开、拖拽、应用可执行权限和 Gatekeeper 原始提示。
3. **首次运行和退出**：角色、透明窗口、托盘、设置、提醒与正常退出。按同提交[桌面回归清单](../regression/CHECKLIST.md)补做关键交互；此清单不代替其余长测。
4. **数据隔离和导入**：先用程序当前已实现的本地导出/预览/下次启动导入，在隔离数据上核对完整性、拒绝错误或未来版本、失败后原数据保留。记录所用数据格式与实际重启回读；不要推断未来专注数据已经包含在当前备份。
5. **升级与回退**：至少选两个实际构建，升级前退出旧实例并备份；核对升级后角色、位置、提醒待处理及导入状态。故意失败或回退只在快照中执行，按旧版兼容备份恢复，验证旧程序能启动且状态符合备份。记录旧/新提交与格式。
6. **卸载与重装**：核对应用文件、快捷方式、用户配置是否保留。预期保留用户数据；如发现删除或损坏立即停止扩大测试，保留证据。不要手动删不确定的目录来制造通过。
7. **分发门槛**：记录 Windows 实际签名提示、Mac 实际签名/公证检查、素材与第三方许可审核结果。此候选未配置生产签名或公证，不填“通过”。

安装器/DMG 的静态 CI 检查不代替此表，Windows 本机测试不能代填 Mac 栏。
