# 公开分发准备与维护边界

状态：技术候选合同，未批准公开发布。2026-09-23按当前集成候选适配；本分支的安装候选 CI 尚未运行。适用 Windows x64 / macOS Apple Silicon；不扩大平台承诺。

## 当前证据与缺口

现有 Actions 已能生成带完整提交、目标平台、文件大小和 SHA-256 的回归包；Windows 是可执行文件，Mac 是保留权限的 `.app.zip`。本分支在同一矩阵追加未签名 NSIS/DMG 候选和包内主程序核对，但尚无本提交的原生 CI 产物或实机结论。M0/M1/G7 当前代码仍待同提交两平台真实桌面验收；旧 v0.2.0 实测不能代替。没有两周试用结论，也没有素材公开分发范围与签名预算的最终决定。

## 分发方案

早期维持手工测试包。本分支候选安装格式为 Windows NSIS 当前用户安装和 Mac DMG（包含 `.app`），拟在各自原生 CI 生成；现有回归包继续单独提供。锁文件中的 `@tauri-apps/cli` 为 2.11.4、Rust `tauri` 为 2.11.5，最终行为仍以本分支 CI 和实机观察为准。Tauri 支持 NSIS 当前用户模式，但具体依赖安装及权限提示仍须干净设备核实。[Tauri Windows 安装说明](https://v2.tauri.app/distribute/windows-installer/)

“离线可用”指已安装后的核心功能不依赖服务。若要承诺新设备断网也能安装，Windows安装包必须携带所需WebView2安装资源并实测；默认下载引导模式不能据此宣称离线安装。安装包体积与离线能力在测试版阶段记录后决定，不默认改用固定版本WebView2并承担长期补丁分发。[WebView2安装选项](https://v2.tauri.app/distribute/windows-installer/#webview2-installation-options)

Mac DMG是分发容器，不替代签名、公证或干净设备启动测试。[Tauri DMG说明](https://v2.tauri.app/distribute/dmg/)

公开版本从通过门槛的同一提交生成，两平台产物一起公布；完整SHA与应用内可见构建身份一致。候选包和正式包名称明确区分，不把仍待验收的构建称为稳定版。不自动执行GitHub Release发布，不把公开仓库可下载CI产物理解为产品已经正式发布。

## 升级、迁移与回退合同

1. 使用托盘正常退出，确认进程结束。升级前保存旧安装包、旧完整提交和用户数据备份；备份与主数据分开，记录格式版本与校验值。
2. 原生导出生成单一、有版本的数据包，包含已实现配置/提醒/专注状态，不导出日志或其他应用数据。导入先验证完整性、支持版本、字段范围与全部条目；预览将覆盖的范围后才应用，不能半成功。
3. 数据变更只经一个应用级事务协调者，迁移先备份；失败保持旧版可读取的原始数据，并明确报告。不能把多个独立文件逐个覆盖当成完整导入成功。具体原子提交协议在G7定稿后记录真实实现。
4. 不支持的新版本格式保留原件、拒绝降级覆盖。回退应用前从对应版本的升级前备份恢复；不能假设旧程序会理解新格式。
5. 安装新版本，核对构建身份，检查角色选择、位置、提醒开关/间隔、未回应事项和安静期。此时不补弹历史周期。失败先停止新版本，再按已验证回退流程恢复，保留去敏问题记录。
6. 卸载行为要明确：应用文件、快捷方式与用户数据分别检查。默认保留用户数据，删除数据只能由用户主动选择；不递归删除猜测目录。

当前 G7-B1/B2/B3 已接入单写入者数据目录、本地备份导出、预览和“下次启动导入”界面；其同提交跨平台 GUI、真实迁移、失败回退及旧版兼容仍未验收。上列流程是待实测的验收合同，不能把代码与自动测试视作真实升级/回退通过。当前数据集范围不自动包含未来 M5 专注状态。自动更新保持范围外，直到至少一次真实跨版本手工升级及回退验证完成。

## 同提交发布验收矩阵

| 环节 | Windows负责人 | Mac负责人 | 证据要求 |
|---|---|---|---|
| 干净安装/首次启动/正常退出 | 所有者 | Mac协作者 | 提交、系统/架构、安装流程、运行时依赖及原始提示 |
| 升级前备份/新版本恢复 | 所有者 | Mac协作者 | 旧新版本与格式、数据保留检查、无重复提醒 |
| 失败回退 | 所有者 | Mac协作者 | 实际执行路径、备份校验、旧版启动与状态检查 |
| 卸载/再安装 | 所有者 | Mac协作者 | 文件/快捷方式/数据保留范围 |
| 签名与下载来源 | 所有者 | Mac协作者 | 最终下载产物的验证结果，不能复用签名前哈希 |
| 常驻与睡眠/显示器恢复 | 所有者 | Mac协作者 | 与最新功能共用清单、实际运行时长和设备缺口 |

每格仅可写通过、失败、待测、无设备、不适用，并附观察。重大启动、无法退出、数据丢失或妨碍工作问题未解决时停止扩大试用。

## 反馈与维护

统一问题入口记录：完整提交/版本、平台、操作步骤、预期与实际、是否可复现。截图和诊断由用户主动选择提供，提醒避免桌面私密内容、任务文本和完整个人路径。没有自动遥测，不上传完整用户配置。

朋友试用的本地记录与共同复盘须按项目实际试用阶段的模板进行；本安装候选未附旧分支的试用模板，也没有据此创建参与者反馈或宣称默认分支入口已启用。

维护人需确认可投入时间、严重问题响应方式和停止维护时的说明；不承诺未经资源评估的响应时限。每个候选发布总结新增价值、已验证、未验证、已知问题及回退方法。连续两轮针对性修改仍无明确价值时先复盘范围，不扩大功能来掩盖缺陷。

## 公开门槛

- 两平台同提交功能与安装/升级/回退证据齐备，严重稳定性问题已解决。
- M4真实试用后明确决定公开；至少所有者与另一参与者有持续帮助的具体例子并愿意继续使用。
- 素材分发范围、代码许可、签名方案/费用及维护责任已确定。
- 发布说明与下载文件一致，用户能独立安装、找回角色、暂停提醒和退出。

任一条件不成立，继续朋友测试，不标记M5-C已完成或公开发行准备就绪。
