# 本次架构整理的执行范围

基线：`windows/v0.2-baseline@a11d0d1`。本次交付长期计划、可执行的模块边界和说明，不在本次交付全部产品路线图。

1. 在 `PRODUCT-PLAN.md` 保存确认过的选择，更新 ROADMAP/TODO/README 导航与状态口径。
2. 在改动前为现有入口建立行为回归：待机、注视、拖动屏蔽、方向切换、160 ms 恢复、采样失败。
3. 提取 `domain/` 纯动画逻辑；`characters/` 提供实际使用的三月七配置；`application/` 编排采样和渲染；`adapters/` 隔离 Tauri、DOM 和浏览器时钟；`main.ts` 只装配和清理。
4. 为停止后的异步采样、定时器释放、拖动失败和配置驱动的渲染补回归；增加自动化依赖边界检查，避免业务逻辑重新依赖 DOM/Tauri。
5. CI 运行前端边界检查、测试、构建，以及双平台 Rust fmt/test/Clippy。Rust 平台坐标算法不在本次改动范围。
6. 完成独立只读审查、修复重要问题，记录实际验证结果；保留旧版本回退路径。

未来提醒模块的状态归属、时间语义、持久化和角色切换边界写进架构文档。未使用的服务、空文件夹、通用事件总线和模拟第二角色不作为本次架构完成的证明。

回退：本次改动不引入持久化迁移。回到重构前提交可恢复旧运行代码；未来有状态存储的阶段必须另行定义版本迁移和回滚策略。
