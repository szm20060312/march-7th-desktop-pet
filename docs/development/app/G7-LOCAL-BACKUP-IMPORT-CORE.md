# G7-B3c1 本地备份导入会话核心

本阶段只提供 crate 内部接口；设置页没有导入按钮，也没有导入文件选择命令。不能把这些测试称为已可供用户操作的迁移功能。

`import_session::read_selected` 接受后续原生选择器提供的本地绝对路径，只读普通文件，拒绝目录、符号链接、Windows 网络共享路径与读取失败；读取最多 `backup_codec::MAX_BACKUP_BYTES + 1` 字节（目前 2 MiB 加一字节）。随后调用现有 `backup_codec::decode`，由三个 Store 的导入验证器检查角色、提醒和桌面状态，并核对包摘要。错误只返回固定代码，不携带路径或备份正文。路径接口保持 crate 私有；后续接线必须由原生文件选择器取得路径，不应授予 WebView 任意文件读取能力。

`ImportSession` 的操作顺序为：从当前设置窗口代次开始选择、后台读取、以同一票据和代次接纳结果、展示只含摘要的预览、显式确认。新选择立即丢弃旧候选；取消、关闭或销毁窗口时调用 `invalidate`，使迟到的读文件结果和旧票据失效。确认只使用内存中冻结的 `ImportFiles`，不会重读外部备份。失败时保留同一预览以便重试；成功后票据即失效，返回事务 ID 和“需手工重启”标记。

确认交给 G7-B2 `DataDirectory::prepare_import`：它会拒绝已有 pending，不覆盖当前三个 Store，只有下次手动启动才整体切换。B3c2 接线时须在选择结果和确认动作处理时重新取得当前设置窗口代次，并在关闭、隐藏、销毁时失效会话；导出和导入系统对话框互斥也在该步实现。这里没有自动重启、文件对话框、前端权限或真实用户数据测试。

回归用独立临时目录证明：预览后源文件改写不影响确认；旧选择、取消和新窗口代次不能确认；无效、未来版本和超大包不会产生 pending；准备写入失败保留旧数据与预览；已有 pending 不被替换；成功确认只在下一次启动切换。突然断电的持久性和 Windows/macOS 桌面交互仍需单独验收。
