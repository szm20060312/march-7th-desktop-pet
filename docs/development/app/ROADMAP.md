# March 7th 独立 App 开发计划

更新时间：2026-09-21  
当前稳定版本：`v0.2.0`  
目标平台：macOS Apple Silicon、Windows 10/11 x64

## 1. 产品目标

将已经通过 QA 的三月七动画资源发展为一个轻量、稳定、可日常使用的跨平台桌宠应用。

核心体验：

- 角色始终清晰、自然地出现在桌面上。
- 注视、待机、移动和点击反馈之间切换稳定，不抖动、不抢占错误状态。
- 默认不干扰用户操作，需要互动时可以快速切换模式。
- macOS 与 Windows 共享动画和状态逻辑，只在系统能力层保留平台适配代码。

## 2. 范围边界

### 1.0 前支持

- macOS Apple Silicon
- Windows 10/11 x64
- 透明置顶窗口
- 鼠标注视、待机、拖动移动
- 基础点击互动
- 托盘菜单、退出入口、位置与设置持久化
- 安装包、签名、公证和发布流程

### 1.0 前不支持

- macOS Intel
- Linux
- Android 或 iOS
- AI 对话、语音合成和角色聊天
- 好感度、养成、换装或复杂物理系统
- 多角色宠物系统

## 3. 开发原则

1. 每个版本只引入一个主要交互闭环。
2. 平台无关逻辑放在 TypeScript/Rust 共享模块，系统调用放在 `platform/`。
3. 任何新动画状态必须定义触发条件、优先级、退出条件和失败回退。
4. macOS 本地验证后必须通过 Windows CI；Windows 专属功能还需要真实 Windows 设备验收。
5. 已通过的移动和注视逻辑不得因后续功能发生退化。
6. 每个稳定里程碑提交 Git 标签，并生成对应阶段报告。

## 4. 版本路线图

### v0.2.0 — 稳定移动基线（已完成）

状态：✅ 完成

- 透明、无边框、始终置顶窗口
- 六帧待机动画
- 真实鼠标驱动的 16 个注视方向
- 拖动时播放向左/向右移动动画
- 使用窗口位移屏蔽拖动期间的注视帧抖动
- Apple Silicon 实机验收

验收记录：[STAGE-0.2.0.md](STAGE-0.2.0.md)

### v0.3.0 — 桌面可用性

目标：让应用能够长期运行，并且不阻挡正常桌面操作。

计划：

- 增加系统托盘菜单
- 提供“点击穿透”和“交互模式”切换
- 增加显示、隐藏、重置位置和退出入口
- 保存并恢复窗口位置
- 窗口落在不可见显示器区域时自动纠正
- 为模式切换提供明确状态反馈

验收标准：

- 点击穿透开启后，下面应用可以正常接收鼠标事件。
- 从托盘切回交互模式后，角色可以再次拖动。
- 应用可以从托盘可靠退出，不需要终端或任务管理器。
- 重启后恢复上次位置；显示器变化后不会丢失窗口。
- 现有待机、注视和左右移动测试全部继续通过。

### v0.4.0 — 角色互动与动画状态机

目标：加入第一组主动互动，并建立统一动画优先级。

计划：

- 单击触发挥手
- 双击触发跳跃
- 建立动画状态机与中断规则
- 动画完成后恢复注视或待机
- 防止单击与双击重复触发
- 为拖动、点击、注视和待机定义统一优先级

建议优先级：

```text
系统/错误状态
  > 拖动移动
  > 点击互动
  > 鼠标注视
  > 待机
```

验收标准：

- 单击只播放一次挥手，双击只播放一次跳跃。
- 互动动画不会被鼠标注视帧打断。
- 拖动可以安全中断点击动画。
- 动画结束后没有空帧、卡帧或错误方向跳变。
- 状态转换拥有独立单元测试。

### v0.5.0 — 设置与生命周期

目标：让用户无需修改文件即可调整桌宠。

计划：

- 设置窗口或托盘设置菜单
- 宠物大小调节
- 始终置顶开关
- 鼠标注视开关与灵敏度
- 开机启动
- 设置持久化与版本迁移
- 恢复默认设置

验收标准：

- 所有设置重启后保留。
- 无效或旧版本配置可以安全回退。
- 缩放后图集仍保持清晰且不改变方向计算。
- 禁用注视时保持稳定待机，不持续进行无效采样。

### v0.6.0 — Windows x64 稳定化

目标：使 Windows 成为可发布的一等平台。

计划：

- Windows 10/11 实机验证
- 混合 DPI：100%、125%、150%、200%
- 多显示器与负坐标验证
- 透明窗口、置顶和点击穿透验证
- 系统托盘、开机启动和位置保存验证
- NSIS 安装包
- Windows 图标、快捷方式和卸载流程

验收标准：

- 单显示器与混合 DPI 多显示器均能正确跟随鼠标。
- 拖动方向与动画在 Windows 上和 macOS 一致。
- 安装、升级和卸载不会遗留运行文件。
- Windows CI 与真实设备测试同时通过。

### v0.7.0 — 性能、可靠性与发布自动化

目标：建立发布前的质量与维护能力。

计划：

- 降低后台轮询与无效重绘
- 应用日志和诊断信息
- 崩溃后的安全恢复
- GitHub Actions 自动构建
- 自动生成校验文件和 Release 草稿
- 依赖更新和安全检查

性能参考目标：

- 静止状态 Apple Silicon CPU 平均占用低于 2%
- 活跃注视状态 CPU 平均占用低于 5%
- 长时间运行无持续内存增长
- 鼠标移动到动画响应的感知延迟低于 100 ms

### v1.0.0 — 首个正式版本

目标：提供可被普通用户安全安装和卸载的双平台版本。

发布门槛：

- macOS Apple Silicon 与 Windows x64 功能一致
- macOS Developer ID 签名和公证完成
- Windows 安装包签名策略确定
- 全新安装、覆盖升级、卸载和回滚测试通过
- README、安装说明、隐私说明和故障排查完整
- 第三方角色素材与代码许可证边界完成审查
- GitHub Release 包含安装包、SHA-256 和双语发布说明

## 6. 每个版本的完成定义

一个版本只有同时满足以下条件才可以标记完成：

1. 计划范围内功能已经实现，非目标没有被顺带加入。
2. 前端测试、Rust 测试、格式检查和 Clippy 通过。
3. 对应平台完成所需的实机验证。
4. README、CHANGELOG 和阶段报告已更新。
5. 工作区干净，构建缓存和本地配置未进入 Git。
6. Git 标签、Release 附件和代码版本一致。
7. 已记录已知限制和明确的下一阶段入口。

## 7. 主要风险

| 风险 | 应对方式 |
|---|---|
| Windows 混合 DPI 坐标不一致 | 尽早在真实 Windows 多显示器环境验证 |
| 点击穿透后无法恢复互动 | 托盘菜单作为始终可用的恢复入口 |
| 新动画破坏已通过状态 | 状态机优先级测试与回归测试 |
| macOS/Windows 行为分叉 | 限制平台代码边界，共享动画逻辑 |
| 签名与公证成本 | v0.7 前确定证书与发布渠道 |
| 第三方角色素材版权 | 保持非官方、非商业声明，发布前完成许可证审查 |

## 8. 建议的下一项任务

下一阶段从 **v0.3.0 桌面可用性** 开始，先实现托盘菜单和可靠退出，再实现点击穿透与交互模式。托盘入口必须先于默认点击穿透，否则用户可能失去恢复互动和退出应用的方式。
