更新时间：2026-09-22

## 行为与边界

- 保留显示、隐藏、重置、退出。增加互斥的“交互模式”“点击穿透”；每次启动为可见、交互模式，原生窗口成功应用后才提交模式状态。失败回滚菜单勾选并记录操作错误，托盘恢复不依赖 WebView。
- 窗口配置先隐藏，先建好托盘，再分步移动到目标屏并核对真实缩放/窗口尺寸，使用实际外窗矩形约束原始保存目标；只有最终位置已核对时才显示和保存。中间事件不会覆盖目标，未完成恢复时退出也不写临时位置。保持不聚焦、不可聚焦。显示会检查可达性；重置及显示/拓扑恢复共用异步 DPI/实际尺寸核对过程，居中与保存使用最终目标屏真实尺寸。重置使用主屏工作区中心，主屏不可用时回退当前屏。进入恢复会取消旧待保存值和缩放请求，停止与只读保护保持不变。
- Rust 独占 `app_config_dir()/desktop-state.json` 写入。v1 仅保存 `version`、`placement.monitor_name` 和工作区相对逻辑偏移 `x/y`，不保存隐藏、穿透状态。
- 保存前核对窗口与所在屏缩放一致，再用物理位置减该屏工作区物理原点并除以缩放；保留 v1 逻辑偏移（包括 Retina 半点），未稳定的 DPI 观察不写入。恢复唯一匹配名称，否则主屏、当前屏、首个可用屏。macOS 窗口物理坐标按窗口缩放报告，显示器物理工作区按各自缩放报告：`coordinates.rs` 在每次目标工作区计算前显式换算源/目标单位，可达性直接比较未取整的全局逻辑边界，所有位置 setter 使用全局逻辑点；Windows 保持全局物理坐标及检查后转换。整窗约束到工作区，超大轴锚定原点，非法/非有限/越界数值安全回退或等待有效观察。
- 500 ms 防抖只有一个可替换的待保存值。单个原生工作线程使用条件变量同时调度文件 IO 与每 2 秒一次的拓扑检查，不依赖前端计时器，也不需要 Tokio。后台检查仅请求显示器几何信息，不读取其他应用。
- 运行中的 DPI 事件独立保留“仍需检查当前矩形”状态；原生或用户移动使旧快照失效，并把检查推迟到连续 500 ms 无移动后。届时读取当前物理位置和真实外窗尺寸，只做必要的工作区约束，不回放旧逻辑坐标；较新移动仍会使已排队检查失效并重新调度。持续移动不会被旧检查反复拉回，配置只读时也保留恢复能力。启动恢复仍保留原始保存目标。移除显示器或工作区变化时纠正不可达窗口。
- 超大窗口可能由相邻屏幕的最大交集决定归属。同 DPI 且真实尺寸、目标锚点均符合时，不强求归属名称一致；混合 DPI 下若已到达暂存锚点仍不能取得目标 DPI，则记录一次降级并移到可达的当前/主屏，再核对真实 DPI、尺寸及可达矩形。未完成这些条件前不显示、不保存，也不以等待时间判定成功。
- 托盘退出与其他正常退出共用异步末次保存：取消待保存/缩放任务、停止监视、完成文件操作，再请求退出；UI 线程不等待或 join 工作线程。停止后的已排队原生回调为空操作。强制结束进程/断电不保证末次保存。
- 同目录独占临时文件写入并同步后，先原子替换 `.json.bak` 为旧有效配置，再原子替换主文件；从不先删除主文件。失败保留旧配置并显示“位置：不可用”；后续合法保存可恢复。损坏或未知版本保留原文件、当次运行禁写，即使外部后来修复也需重启。
- 禁用状态菜单显示“位置：已保存 / 待保存 / 不可用”，错误仅写 stderr。JSON 错误只记录位置与类别，不打印配置内容。

## 文件职责

| 文件 | 职责 |
|---|---|
| `desktop/mod.rs` | 原生托盘、窗口操作、UI/单工作线程连接 |
| `desktop/coordinates.rs` | 平台坐标边界、跨显示器比较与原生位置参数 |
| `desktop/geometry.rs` | 单目标坐标换算、显示器选择、工作区约束 |
| `desktop/state.rs` | 模式提交、运行/停止状态、单待保存值与状态修订号 |
| `desktop/store.rs` | 有类型 v1 IO、只读保护、临时文件/备份/替换 |

依赖只增加直接 `serde_json` 声明，Cargo 自动更新锁文件中的应用依赖列表，无版本升级。前端与角色资源没有修改。
