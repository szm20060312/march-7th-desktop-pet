# 长期方向与交付计划

更新：2026-09-21。来源：与项目所有者逐项确认的产品选择。

## 产品方向

做一个可更换角色的桌面陪伴工具，以温和的日常提醒作为第一个实用场景。先服务自己和少数朋友，通过真实使用反馈判断是否继续扩大范围。

角色不是通知的装饰：用户点击、完成提醒或选择稍后时，角色用动作和符合其性格的预设短句回应。首版不随机发起闲聊，也不引入 AI 对话、复杂养成、角色商店或角色制作平台。

## 首个可日常使用版本

| 能力 | 已确认的要求 |
|---|---|
| 角色 | 内置两个角色，可切换，各有动画与预设回应短句 |
| 互动 | 保留注视和拖动，增加点击挥手、双击跳跃 |
| 提醒种类 | 喝水、起身活动、休息眼睛；分别开关、调整间隔 |
| 提醒呈现 | 动作与气泡，提供“完成／稍后提醒”；未操作则自动收起 |
| 完成 | 每项单独确认，从该项完成时间重新计时 |
| 未回应 | 保持待处理，不反复弹出；收起不等于完成 |
| 稍后 | 所有提醒统一进入安静期；到期合并提示待处理事项 |
| 平台 | Windows x64 与 macOS Apple Silicon 同步开发、同版本验收 |
| 测试分工 | 所有者负责 Windows，朋友或协作者负责 Mac |
| 首轮用户 | 自己和少数朋友 |

切换角色只改变表现，不重置提醒进度。提醒语义由应用统一定义，角色资源不能改变提醒规则。

## 阶段与验收

阶段编号用于表达先后依赖，不承诺未经估算的发布日期。原有 v0.3 桌面可用性、v0.4 角色互动仍保留；提醒与两周试用纳入后续版本，具体版本号在阶段启动时确定，不把文档计划当成发布记录。

### M0：基线与架构基础

继承 v0.2.0 的待机、16 方向注视、左右移动和 160 ms 恢复规则。把纯逻辑、运行调度、角色配置及系统/UI 适配分开，为状态转换和生命周期建立自动化回归。

Windows 分支 `a11d0d1` 已记录单显示器 100%/150%/200% DPI 实测；这是既有基线记录，不代表本次重构已实测。多显示器及混合 DPI 仍需单独记录，不重复宣称已通过。

出口：前端测试和构建通过、双平台 Rust 检查通过；重构后的 Windows/Mac 人工检查完成后才能标记运行基线验收完成。

### M1：长期常驻（v0.3）

实现托盘、退出、显示/隐藏、交互/点击穿透、重置位置、位置保存与越界恢复。先建立始终可用的托盘恢复入口，再开放点击穿透。

出口：无需终端即可退出；穿透后可恢复互动；显示器变化后可找回窗口；两平台均验收。

### M2：角色互动与切换（v0.4）

接入单击/双击判定、互动动画优先级及短句；准备第二个真实角色；提供内置角色切换并保存选择。资源清单定义各角色动作和台词，通用调度不能按角色 ID 分支。

出口：两个角色均完成注视、拖动、点击和反馈检查；拖动可中断互动，动画结束正常回退；切换不影响应用状态。第二个角色人选和素材尚待确定。

### M3：日常提醒闭环

独立提醒状态与计时模块，随后接入气泡和角色反馈。完成/稍后/自动收起是三种不同事件。统一安静期优先于各项到期展示，各项完成独立计时。

出口：到期合并、分别完成、全局稍后、未回应不重复打扰均有测试；重启、睡眠恢复、系统时钟变化不造成历史提醒连弹；穿透模式下仍可操作提醒。

需先决策：默认间隔、安静期与气泡停留时长、待处理事项的再次查看入口、隐藏/全屏时的提醒政策、穿透下的交互方式。这些不是当前已实现功能。

### M4：双平台朋友试用两周

提供 Windows 与 Mac 可运行的测试产物、安装/升级/卸载说明和反馈模板。可采用未签名测试版，但说明启动方式；正式签名与公开分发继续保留在发布阶段。

核心指标：提醒是否帮助用户执行日常动作，而且不烦。底线：稳定、省心、不妨碍正常操作。观察指标：是否愿意多数日子主动开启、是否感到陪伴。

不把“点击完成次数”当成真实健康行为，也不把自动收起当成完成。先用手工反馈，无需遥测后台。

出口：汇总真实反馈和未解决问题。稳定性不足先修复；提醒经常被关闭先调节奏；不要用增加功能掩盖核心体验问题。

### M5：按反馈扩展

先优化角色动作和短句，再单独验证专注陪伴，之后才考虑任务陪伴。公开测试、自动更新、签名及完善分发，在小范围价值成立后推进。

## 开发与发布规则

- Windows 与 Mac 共用产品规则和前端逻辑；系统差异封装在适配层。
- 每个阶段拆为 Shared / Windows / macOS / QA。测试版可按平台提供，正式阶段完成必须两边过关。
- 自动化结果、历史实测、本次实测分开记录；CI 不等于桌面视觉验收。
- 每次变更写明行为、测试、剩余限制；不移动旧标签，不改 `releases/v1.0.0` 封存包。
