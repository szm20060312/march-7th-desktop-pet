# 当前 main 与 G7 开发栈集成候选

基线为 `main@cbf5753`（含 PR #12）；合入开发栈顶端 `4963d2c`。本候选在隔离分支形成，仍需 Windows/macOS 同提交 CI、实机回归和独立代码审查；没有合并主线或公开发布。

冲突裁决：`lib.rs` 使用新架构唯一 Tauri context、setup/run 和命令注册，不复制 PR #12 的旧版状态栏 Builder。`desktop/mod.rs` 仍创建唯一原生托盘，保留现有显示、隐藏、重置、穿透、角色和提醒菜单；仅 macOS 增加“切换到当前桌面”。Cargo 的 `tray-icon` feature 维持一份。主线关于 Apple Silicon 和旧版状态栏的历史记录保留，当前候选的验收另记。

Mac 操作先隐藏主窗口，约 80 ms 后将动作排回主线程。其代次在再次切换、显示、隐藏、重置、关闭窗口、销毁窗口或退出时失效；过期回调不能把窗口重新显示。有效回调调用现有显示函数，继续受不可聚焦和显示器可达性恢复逻辑约束，不从后台线程直接操作窗口。切换不改角色、提醒进度、导入待办或数据目录锁。

Windows 本地自动测试验证代次竞争、前端、Rust、打包身份和架构边界。Mac Spaces 的隐藏再显示是否确实切换到当前桌面、全屏空间下表现、焦点和显示器变化，必须由协作者在本候选的同一提交上实测；自动测试与旧版 PR #12 实测均不能替代。
