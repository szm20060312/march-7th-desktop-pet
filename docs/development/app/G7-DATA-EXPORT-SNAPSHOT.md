# G7-B3b1：本地备份候选的状态边界

本阶段提供纯 Rust 的内部接口，从当前运行中的角色与提醒快照、以及调用者明确确认的桌面位置资格，构造一组完整的 `ImportFiles`。三个模块分别执行自身的可导出状态检查、v1 序列化和格式验证；协调层只在三项均成功后返回候选，并再次经过 B2 的整组校验。候选可以交给 B3a 的 `backup_codec::encode`，但本阶段尚未把这些接口接入桌面命令。

角色仅允许运行中的 `Default` 或 `Saved` 快照，所选 ID 必须仍在内置目录。`Fallback`、`SessionOnly`、`SaveFailed`、停止后的缺失快照均拒绝。默认角色显式编码为新的 v1 记录，不读取旧磁盘文件。

提醒仅允许无保存错误和运行错误的 `Default` 或 `Saved` 快照。v1 记录包括三项设置和进度、暂停、quiet 与 `snoozePending`，使用现有提醒状态验证器检查交叉约束。revision、presentation 和 UI 状态不写入。加载中、未保存、只读、已停止或非法组合均拒绝，不能用旧磁盘值或默认回退值填补。

桌面调用方必须提供 `Captured(Placement)`、`NeverSaved` 或 `Unavailable`。前者编码为现有 v1 配置并校验有限坐标；明确从未保存映射为 B2 的缺省位置；不可用直接拒绝。**这个接口没有捕获窗口、等待位置保存、判断显示器拓扑或识别回退位置的能力**，这些资格必须由后续原生接线在调用前确认。

本阶段没有文件对话框、文件读写、Tauri 命令、设置界面或用户可用的“导出”按钮。测试仅使用合成快照与位置；没有使用现有用户配置，也不能把本阶段测试当作 Windows/macOS 桌面实测或完整数据迁移验收。
