## 审查与浏览器观察

两次任务审查、各一次修复复审及最终整体审查均通过。修复覆盖缺动作回待机、缺短句清旧文本，以及首次原生监听失败时提示真实的重启路径。此前 M1 测试清单声称没有位置保存的矛盾，已在本次完整清单和结果表中修正。

浏览器预览使用真实目录、图集、模型、手势、运行器、视图与预载控制器，仅模拟系统采样和原生拖动：

- 两角色均能加载、呈现；240×260窗口内角色单格192×208，顶部40、底部12 CSS像素。
- 观察到单击挥手及短句、双击跳跃、短句自动消失，文字未遮挡角色。
- 模拟拖动只产生一次宿主请求并清除短句；这不是系统窗口拖动测试。
- 模拟图集失败保留旧角色，再次选择可恢复；较长角色名的错误提示已缩短并复看，未再截断。

预览与自动测试不证明真实托盘派发、非聚焦窗口输入、穿透恢复、实际文件保存、混合缩放或长期占用。雷电外观基准已由所有者确认，最终动作节奏与短句仍待验收；生成预览与生产动作间隔不同，不能混用两者结论。
