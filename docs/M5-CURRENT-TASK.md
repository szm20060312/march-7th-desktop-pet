# M5-B 当前一件事：技术候选

开始专注时可填一个任务名，留空只计时。任务完成或放弃不结束计时；计时自然结束不完成任务。当前会话不追加第二个任务，下次开始可换名称。不保存任务列表、历史、积分或外部同步。

## 数据与隐私

- `focus.json` 内层 version 2 明确保存 `task: null | { name, status }`，status 为 active/completed/abandoned。旧内层 v1 经严格解析补无任务，完整保留原计时与反馈状态；恢复时若需要推进时间，沿用原专注引擎规则。唯一 focus worker 原子写入成功后才发布升级/状态。
- 外层四文件活动数据集和备份继续使用 v2；外层 v1/v2 和旧内层 v1 均可导入。校验和仍覆盖原始字节，不在核对摘要前重编码。4 KiB focus、2 MiB 备份上限不变。未来/损坏状态保留原件并保护。
- 名称先拒绝控制字符，再按 Unicode White_Space trim；空白无任务，最多 80 Unicode 标量且 UTF-8 ≤256 字节。前后端规则一致，补充平面字符不按 UTF-16 单元误计数。
- 名称只通过设置页 focus API/事件和用户主动备份流转；角色与提醒页无 focus 命令访问，角色仅收到 revision/status，不收到名称。设置页错误日志仅写操作阶段。备份预览仅输出 taskStatus，无正文。
- 每次已提交的任务终态仅产生一次 live 响应；重复同结果不重发，互斥另一结果拒绝。启动恢复、读取快照、角色切换不重播。隐藏角色或已过期/已被更新替代的原生回调不积压回应。
