# 交互状态映射

宠物本身是状态驱动的动画资源，不包含独立业务脚本。具体触发时机由 Codex 应用决定。

| 应用情境 | 动画状态 | 表现 |
|---|---|---|
| 无任务或无明确目标 | `idle` | 呼吸、眨眼、轻微晃动 |
| 向右移动或拖动 | `running-right` | 右向移动步态 |
| 向左移动或拖动 | `running-left` | 左向移动步态 |
| 出现、问候 | `waving` | 手臂挥手 |
| 活跃或成功反馈 | `jumping` | 起跳、腾空、落回 |
| 任务失败或错误 | `failed` | 低落、失望反应 |
| 等待确认、授权、输入 | `waiting` | 期待、询问姿态 |
| 正在执行任务 | `running` | 专注查看相机/处理任务 |
| 正在检查结果 | `review` | 认真观察、歪头审阅 |
| 指针或关注目标有明确方向 | look rows | 16 个方向的眼睛、头部和上身跟随 |
| 指针进入方向死区 | `idle` | 回落到中性待机 |

## 当前未实现的独立交互

- 点击角色触发台词
- 连续点击后的情绪变化
- 喂食、换装、好感度或成长系统
- 音效、语音和粒子效果
- 时间、天气或节日状态

如果未来增加这些能力，应先确认 Codex 宠物运行时是否提供对应事件接口。不要把额外交互硬编码进精灵图契约。
